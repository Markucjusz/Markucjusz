### 🚀 Moje projekty

#### 1. Odkrywam Przyszłość — Radar Naukowy
W pełni zautomatyzowany agregator odkryć naukowych, technologicznych i kosmicznych działający bez płatnego serwera (CI/CD na GitHub Actions).
- 🌐 **[Otwórz portal na żywo](https://markucjusz.github.io/Odkrywam-Przyszlosc/)**
- 📂 **[Kod źródłowy i silnik RSS/APOD](https://github.com/markucjusz/Odkrywam-Przyszlosc)**

#### 2. Kroniki Cienia — Turowa Gra Przeglądarkowa RPG
Gra RPG w klimacie dark fantasy tworzona w czystym **HTML, CSS i JavaScript**, osadzona w mrocznym świecie zapomnianych krain.
- 🌐 **[Portal gry, opis świata i Karczma (komentarze)](https://markucjusz.github.io/kroniki-cienia-portal/)**
- ⚔️ **[Zagraj bezpośrednio w przeglądarce](https://markucjusz.github.io/kroniki-cienia/)**
- 📂 **[Kod źródłowy gry](https://github.com/markucjusz/kroniki-cienia)**
